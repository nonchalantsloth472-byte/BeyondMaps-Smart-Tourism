# BeyondMaps

### Explore beyond the obvious.

BeyondMaps is a smart tourism platform designed to help travelers discover personalized journeys, less-crowded destinations, authentic local experiences, tourism insights, and safety information.

### Backend

* FastAPI
* Python
* MySQL

## ✨ Features

* Personalized trip planning
* Smart destination discovery
* Crowd intelligence and prediction
* Less-crowded alternative recommendations
* Local experiences
* Tourism insights and analytics
* Tourist safety information
* User authentication and travel preferences

## 🚀 Getting Started

### Frontend

```bash
npm install
npm run dev
```

### Backend

```bash
cd backend
pip install -r requirements.txt
uvicorn main:app --reload
```

API documentation:

```text
http://127.0.0.1:8000/docs
```

## 🌱 Vision

BeyondMaps aims to make tourism more personalized, sustainable, distributed, local, and safe by helping travelers explore beyond conventional tourist routes.
